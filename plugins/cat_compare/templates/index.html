Progression Compare (Fixed Baseline)

Use this when

  • Best when you have two or more assessments, and you want to see trends for your AppDynamics configuration maturity.
  • The tool will compare the selected baseline against each later selected assessment.
  • Use one controller per progression run.
  • Folder and file names below are examples; workbook filenames must include MaturityAssessment plus apm, brum, or mrum.
  • If files are scattered, copy the non-raw APM, BRUM, and MRUM MaturityAssessment workbooks into one clean staging folder first.
  • Group dated assessments in child folders, or keep dated workbook files directly in the selected folder.
  • If nested-folder guidance appears, browse one level deeper and select the folder containing the assessment folders or workbooks.
  • Select the earliest assessment as the baseline, then tick the later assessments to compare against it.

Recommended: dated assessment folders
